# TaskFlow – Task Management Application

A simple and user-friendly task management application designed to organize daily activities, track tasks, and improve productivity.

## 🚀 Live Demo

**[View TaskFlow – Live Website](https://taskflow-app-soheli-panda.vercel.app/)**

## 📌 About the Project

TaskFlow is a task management and productivity application that helps users manage their daily tasks efficiently. It provides an interactive interface for creating, updating, deleting, and organizing tasks.

The application focuses on usability, responsive design, and client-side data persistence to provide a smooth task management experience.

## ✨ Features

- **Add Tasks:** Create new tasks with ease.
- **Edit Tasks:** Update existing task details.
- **Delete Tasks:** Remove tasks that are no longer needed.
- **Task Management:** Organize and manage daily activities.
- **Data Persistence:** Retain task data on the client side.
- **Responsive Design:** Access the application across different screen sizes.
- **Interactive Interface:** Simple and user-friendly experience.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Soheli-05/task-management-app.git
   ```

2. Navigate to the project folder:

   ```bash
   cd task-management-app
   ```

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

## 🎯 Project Objective

The main objective of this project is to develop a practical productivity application while applying frontend development concepts, CRUD operations, state management, and client-side data persistence.
